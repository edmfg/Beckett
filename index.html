Production pipeline · pre-produced, not live-generated

How the creative gets built

All ads are pre-produced ahead of broadcast. A brand briefs Gemini on a library of creative variants — one per moment-type and meme combination — and Gemini renders the full library days before kickoff. At broadcast, a trigger classifier matches the live sport moment to the right variant and serves it. The contextual magic is in the matching, not in any real-time generation.

Model
Nano Banana Pro — gemini-3-pro-image-preview
Inputs
Meme template + friend / hero face + team colors + stadium (up to 14 reference images per render)
Render time
~8 seconds per image — fast enough to iterate a library of 50–200 variants in a single agency session
Cost
~$0.13 per image · the full library typically lands under $50 in compute
Text rendering
Native — handles meme captions (Doge, "this is fine," etc.) without OCR or compositing tricks
Iteration
Prompt-test on Nano Banana 2 (faster, cheaper) → final render on Nano Banana Pro
